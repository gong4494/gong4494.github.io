# MIDI files for the speed player

`midispeed.html` loads any `.mid` you drag onto it. It also has a **Hey Jude**
button that looks for one specific file:

    midi/heyjude.mid

Drop your own copy there with that exact name and the button will work.

Nothing is committed here by default. "Hey Jude" (Lennon–McCartney, 1968) is
still under copyright, so the song's note data is not bundled with this repo —
supply your own file.

Public-domain demo tunes (Ode to Joy, Twinkle Twinkle) are generated in the
page itself and need no file.
